# Python System Information Tool

## Overview

This project is a beginner-friendly Python utility that displays basic information about the computer on which it is running.

The project is part of my hands-on IT and cybersecurity training and is designed to strengthen my understanding of Python while applying programming concepts to a practical IT task.

## Project Goals

* Practice Python fundamentals
* Work with Python modules
* Retrieve basic system information
* Format information for readable terminal output
* Connect programming skills with IT support and troubleshooting concepts

## Information Displayed

The program will display information such as:

* Operating system
* Computer/host name
* Processor information
* Python version
